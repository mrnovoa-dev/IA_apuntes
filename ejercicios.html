Ejercicios del curso

Ejercicios de todas las unidades, cada bloque con su unidad indicada en el índice. Empiezan con 27 ejercicios encadenados de la UD2 que llevan de print() a un pipeline de datos listo para Machine Learning, 10 más de refuerzo de Python básico (Bloque F), 4 de datos sin Pandas (Bloque G), 5 para ver por dentro la IA generativa (Bloque H), 6 de clases y Python avanzado (Bloque I), 6 de Pandas a fondo (Bloque J), 3 de cadenas (Bloque K), 8 de deep learning con números (Bloque L), 5 de listas a fondo (Bloque M), 5 de estadística y redes (Bloque N), 3 de redes neuronales desde cero (Bloque O), 4 de tuplas (Bloque P) y 4 que llevan las chuletas al código: decoradores, NumPy, bucles de entrenamiento y Terraform (Bloque Q) y 4 de machine learning con criterio: línea base y métricas, número de grupos, series temporales y revisión crítica (Bloque R) y 4 de Python a fondo con preguntas tipo entrevista (Bloque S). Cada uno tiene enunciado, conceptos, una pista y la solución explicada (plegadas: ábrelas solo después de intentarlo) y un reto extra.

Cómo trabajar cada ejercicio

  1. Lee el enunciado y escribe el pseudocódigo en papel: ¿qué entra, qué se calcula, qué sale?
  2. Programa tu versión en Jupyter o Colab. Si te atascas, abre la pista.
  3. Compara con la solución. Si es distinta pero funciona, también vale: explica la diferencia.
  4. Haz el reto extra. Si usas una IA para generar código, anótalo en tu diario de prompts (prompt, código obtenido, ¿funcionó a la primera?, qué corregiste).

Dataset común para E21–E27

Los siguientes ejercicios usan un CSV de ventas sucio a propósito (duplicados, huecos, un precio negativo y una región mal escrita). Ejecuta esto una vez para crearlo:

import numpy as np
import pandas as pd

rng = np.random.default_rng(42)
n = 60
df = pd.DataFrame({
    "fecha": pd.date_range("2026-01-05", periods=n, freq="W").strftime("%Y-%m-%d"),
    "region": rng.choice(["Norte", "Sur", "Este", " norte"], n, p=[.3, .3, .3, .1]),
    "producto": rng.choice(["camiseta", "gorra", "sudadera"], n),
    "unidades": rng.integers(1, 30, n).astype(float),
    "precio": rng.choice([12.0, 9.5, 29.9], n),
})
df.loc[[3, 17, 40], "unidades"] = np.nan      # huecos
df.loc[25, "precio"] = -1                     # valor imposible
df = pd.concat([df, df.iloc[[5, 6]]], ignore_index=True)   # 2 duplicados
df.to_csv("ventas.csv", index=False)
