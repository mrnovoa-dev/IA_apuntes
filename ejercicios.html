Ejercicios de Python · UD2

27 ejercicios encadenados que llevan de print() a un pipeline de datos listo para Machine Learning. Cada uno tiene enunciado, conceptos, una pista y la solución explicada (plegadas: ábrelas solo después de intentarlo) y un reto extra.

Cómo trabajar cada ejercicio

  1. Lee el enunciado y escribe el pseudocódigo en papel: ¿qué entra, qué se calcula, qué sale?
  2. Programa tu versión en Jupyter o Colab. Si te atascas, abre la pista.
  3. Compara con la solución. Si es distinta pero funciona, también vale: explica la diferencia.
  4. Haz el reto extra. Si usas una IA para generar código, anótalo en tu diario de prompts (prompt, código obtenido, ¿funcionó a la primera?, qué corregiste).

Bloque A · Fundamentos (E1–E12)

E1 · Mostrar un mensaje 🟢

Enunciado. Escribe un programa que muestre por pantalla Hola, Python.

Conceptos: print(), cadenas de texto (strings).

Reto extra: muestra tu nombre, tu curso y tu instituto en tres líneas usando un solo print() (pista: \n).

E2 · Suma de dos números 🟢

Enunciado. Pide al usuario dos números enteros y muestra su suma.

Conceptos: input(), conversión con int(), variables, f-strings.

Pista

input() siempre devuelve texto. ¿Qué pasa si sumas "3" + "4"? Pruébalo antes de convertir.

Reto extra: muestra también la resta, el producto, la división real (/), la división entera (//) y el resto (%).

E3 · Área de un triángulo 🟢

Enunciado. Calcula el área de un triángulo a partir de su base y su altura (pueden tener decimales).

Conceptos: float(), operadores * y /, fórmulas.

Reto extra: calcula el área de un triángulo conocidos sus tres lados con la fórmula de Herón (import math, math.sqrt).

E4 · ¿Par o impar? 🟢

Enunciado. Pide un número entero y di si es par o impar.

Conceptos: operador módulo %, if / else.

Pista

El resto de dividir un número par entre 2 es siempre 0: 10 % 2 → 0, 7 % 2 → 1.

Reto extra: di además si el número es múltiplo de 3, de 5 o de ambos.

E5 · El mayor de tres números 🟢

Enunciado. Pide tres números y muestra cuál es el mayor.

Conceptos: comparadores (>, >=, ==), operadores lógicos (and, or), if / elif / else.

Reto extra: ordena los tres números de menor a mayor sin usar sorted().

E6 · Contar del 1 al N 🟢

Enunciado. Pide un número N y muestra todos los números del 1 al N.

Conceptos: bucle for, range(), bucle while.

Pista

range(inicio, fin) no incluye fin. ¿Qué tienes que poner para que llegue hasta N?

Reto extra: muestra solo los múltiplos de 3 hasta N y su suma. Después, la tabla de multiplicar de N.

E7 · Suma de una lista sin sum() 🟢

Enunciado. Dada la lista [10, 25, 30, 15, 20], calcula su suma sin usar sum().

Conceptos: listas, recorrido con for, acumulador.

Reto extra: calcula con el mismo patrón la media, el máximo y el mínimo, sin max() ni min().

E8 · Contar vocales 🟢

Enunciado. Pide una frase y cuenta cuántas vocales tiene.

Conceptos: recorrer una cadena, .lower(), operador in.

Reto extra: cuenta las consonantes y los espacios. Esto es la base del procesado de texto de la unidad de lenguaje natural.

E9 · ¿Es primo? 🟡

Enunciado. Crea una función es_primo(n) que devuelva True si n es primo.

Conceptos: funciones, return, salida anticipada de un bucle, optimización.

Pista

Basta con probar divisores hasta la raíz cuadrada de n: si n = a × b y los dos fueran mayores que √n, el producto sería mayor que n.

Reto extra: escribe primos_hasta(n) que devuelva la lista de primos menores que n y mide cuánto tarda con n = 100 000.

E10 · Contador de palabras 🟢

Enunciado. Pide una frase y muestra cuántas palabras contiene y cuáles son.

Conceptos: .split(), len(), listas.

Reto extra: muestra la palabra más larga y cuántas veces aparece cada palabra (pista: diccionario).

E11 · Gestión de notas 🟡

Enunciado. Pide 5 notas, guárdalas en una lista y muestra la media, la nota más alta, la más baja y la calificación (Insuficiente, Suficiente, Bien, Notable, Sobresaliente).

Conceptos: .append(), sum(), len(), max(), min(), elif encadenados.

Reto extra: valida que cada nota esté entre 0 y 10 y vuelve a pedirla si no lo está (while).

E12 · Escribir y leer un archivo 🟡

Enunciado. Guarda en un archivo de texto una frase que escriba el usuario. Después abre el archivo y muestra su contenido.

Conceptos: open(), modos "w", "r" y "a", with, codificación UTF-8.

Reto extra: crea un pequeño diario: cada ejecución añade una línea con la fecha (datetime.date.today()) y el texto escrito.

Competencias del bloque A: leer datos del usuario, decidir con condiciones, repetir con bucles, crear funciones reutilizables, trabajar con archivos y calcular estadísticas sencillas.

Bloque B · Datos con Python puro (E13–E17)

Estos ejercicios hacen a mano lo que después hará Pandas en una línea. Entenderlos así es lo que permite usar Pandas sabiendo qué ocurre por dentro.

E13 · Una tabla como lista de diccionarios 🟡

Enunciado. Representa 5 alumnos (nombre, edad, nota, grupo) como una lista de diccionarios. Muestra la tabla alineada, la nota media, los alumnos con nota ≥ 7 y el top 3.

Conceptos: diccionarios, listas por comprensión, sorted() con key.

Pista

Cada diccionario es una fila; cada clave, una columna. Para quedarte con una columna: [a["nota"] for a in alumnos].

Reto extra: calcula la nota media de cada grupo (anticipa E16).

E14 · Validar datos con excepciones 🟡

Enunciado. La lista ["17", "dieciséis", "", "18", "-3", "16", "150", "17.5"] contiene edades escritas a mano. Convierte las válidas a int y genera un informe con cada error: fila, valor y motivo.

Conceptos: try / except, raise, reglas de calidad de datos.

Reto extra: en lugar de descartar los vacíos, sustitúyelos por la mediana de las edades válidas (es lo que hace fillna).

E15 · Estadística descriptiva a mano 🟡

Enunciado. Con datos = [7, 5, 8, 9, 5, 6, 10, 5, 7, 8], programa tus propias funciones de media, mediana, moda y desviación típica, y compáralas con el módulo statistics.

Conceptos: funciones, ordenación, diccionario de frecuencias, fórmula de la desviación.

Reto extra: añade un 0 a los datos. ¿Cuánto cambia la media? ¿Y la mediana? Explícalo.

E16 · Agrupar y agregar (un group by a mano) 🟡

Enunciado. Con una lista de ventas (región, producto, importe), calcula el total, el número de ventas y la media por región.

Conceptos: diccionarios como acumuladores, dict.get(), collections.defaultdict.

Reto extra: agrupa por dos claves a la vez, (región, producto).

E17 · Leer y escribir CSV 🟡

Enunciado. Lee un CSV de notas (nombre,asignatura,nota), convierte las notas a número saltando las vacías, calcula la media de cada asignatura y guárdala en resumen.csv.

Conceptos: módulo csv, DictReader, conversión de tipos, escritura.

Reto extra: descarga un CSV real de abertos.xunta.gal y repite el proceso. Observa qué problemas de formato aparecen (separador ;, comas decimales…).

Bloque C · NumPy (E18–E19)

E18 · Vectores y operaciones vectorizadas 🟡

Enunciado. Con las temperaturas de una semana en un array de NumPy: muestra su forma y tipo, la media, máximo y mínimo, conviértelas a Fahrenheit sin bucles, filtra los días de más de 15 °C y calcula la variación día a día. Compara la velocidad de NumPy con la de una lista.

Conceptos: np.array, shape, dtype, operaciones elemento a elemento, máscaras booleanas.

Reto extra: genera 1000 notas aleatorias con np.random.default_rng().normal(6, 1.5, 1000), recórtalas entre 0 y 10 con np.clip y cuenta cuántos aprobados hay.

E19 · Matrices y álgebra lineal 🔴

Enunciado. Con dos matrices 2×2: súmalas, multiplícalas elemento a elemento y como producto matricial, traspón una y calcula un determinante. Resuelve el sistema 2x + y = 5, x + 3y = 10. Calcula el negativo de una imagen en escala de grises.

Conceptos: @, .T, np.linalg.det, np.linalg.solve, la imagen como matriz.

Reto extra: comprueba que A @ B no es igual a B @ A. ¿Qué propiedad de la multiplicación de números se pierde con matrices?

Bloque D · Pandas (E20–E22)

E20 · Primeros pasos con DataFrames 🟡

Enunciado. Crea un DataFrame con 6 alumnos (nombre, edad, nota, grupo). Muestra sus primeras filas, forma, columnas y tipos; selecciona columnas; filtra por una y por dos condiciones; accede a celdas con loc e iloc; añade una columna aprobado y ordena por nota.

Conceptos: DataFrame, Series, selección, filtrado booleano, loc / iloc.

Reto extra: carga el dataset penguins de Seaborn (sns.load_dataset("penguins")) y responde: ¿cuántas especies hay? ¿Cuál es la más pesada de media?

Dataset común para E21–E27

Los siguientes ejercicios usan un CSV de ventas sucio a propósito (duplicados, huecos, un precio negativo y una región mal escrita). Ejecuta esto una vez para crearlo:

import numpy as np
import pandas as pd

rng = np.random.default_rng(42)
n = 60
df = pd.DataFrame({
    "fecha": pd.date_range("2026-01-05", periods=n, freq="W").strftime("%Y-%m-%d"),
    "region": rng.choice(["Norte", "Sur", "Este", " norte"], n, p=[.3, .3, .3, .1]),
    "producto": rng.choice(["camiseta", "gorra", "sudadera"], n),
    "unidades": rng.integers(1, 30, n).astype(float),
    "precio": rng.choice([12.0, 9.5, 29.9], n),
})
df.loc[[3, 17, 40], "unidades"] = np.nan      # huecos
df.loc[25, "precio"] = -1                     # valor imposible
df = pd.concat([df, df.iloc[[5, 6]]], ignore_index=True)   # 2 duplicados
df.to_csv("ventas.csv", index=False)

E21 · Limpieza de datos 🟡

Enunciado. Carga ventas.csv, diagnostica sus problemas (faltantes, duplicados, valores imposibles, texto inconsistente) y corrígelos.

Conceptos: isna(), duplicated(), drop_duplicates(), fillna(), métodos .str, astype(), to_datetime().

Reto extra: en vez de rellenar los huecos, bórralos con dropna(). ¿Cambian mucho las ventas totales? ¿Cuándo es preferible cada opción?

E22 · Agrupar con groupby 🟡

Enunciado. Con los datos limpios y una columna importe = unidades × precio: ventas totales por región; número de pedidos y ticket medio por región; tabla dinámica región × producto; porcentaje de cada pedido sobre el total de su región.

Conceptos: groupby, agg con nombres, pivot_table, transform.

Reto extra: ¿qué producto vende más en cada región? (pista: idxmax sobre la tabla dinámica).

Bloque E · Visualización y proyecto (E23–E27)

E23 · Gráficos con Matplotlib 🟢

Enunciado. Dibuja en una misma figura: un gráfico de líneas (temperatura media por mes), uno de barras (lluvia por mes) y uno de dispersión (horas de estudio frente a nota).

Conceptos: plt.subplots, plot, bar, scatter, títulos y ejes.

Reto extra: añade al gráfico de dispersión la recta de tendencia con np.polyfit(horas, nota, 1).

E24 · Pandas + Matplotlib 🟡

Enunciado. Con el CSV de ventas limpio, dibuja: ventas por región (barras horizontales ordenadas), ventas por mes (línea) e histograma de unidades por pedido.

Conceptos: .plot() de Pandas, resample sobre fechas, histogramas.

Reto extra: repite los gráficos con Seaborn (sns.barplot, sns.lineplot, sns.histplot) y compara el resultado.

E25 · Pipeline ETL 🔴

Enunciado. Organiza la limpieza de E21 como un pipeline de tres funciones, extraer, transformar y cargar, que lea ventas.csv y genere ventas_limpio.csv con columnas nuevas mes e importe.

Conceptos: ETL, funciones con una responsabilidad, reproducibilidad.

Reto extra: añade una función validar(df) que compruebe con assert que no quedan huecos, duplicados ni precios negativos.

E26 · Análisis exploratorio (EDA) 🔴

Enunciado. Sobre ventas_limpio.csv sigue los pasos del EDA: forma y tipos, faltantes, estadísticas, frecuencias de las categóricas, correlaciones, atípicos con la regla del IQR, un diagrama de caja y uno de dispersión, y una conclusión escrita.

Conceptos: describe, value_counts, corr, cuartiles, IQR, boxplot.

Reto extra: haz el EDA del dataset titanic de Seaborn y responde: ¿influyó la clase del billete en la supervivencia?

E27 · Normalización para Machine Learning 🔴

Enunciado. Con un DataFrame de edad (16–18) e ingresos (12 000–52 000), aplica a mano la normalización min-max y la estandarización z-score, y comprueba que coinciden con MinMaxScaler y StandardScaler de scikit-learn.

Conceptos: escalado, fit_transform, por qué los modelos lo necesitan.

Reto extra: añade una persona con ingresos de 500 000 €. ¿Qué le pasa a la columna min-max? Prueba RobustScaler.

Después de E27 ya tienes el pipeline completo de preparación de datos: leer (E17) → limpiar (E21) → explorar (E15, E26) → separar variables (E22) → escalar (E27). La UD5 añade el último paso: entrenar y evaluar un modelo. Mira la unidad de Machine Learning.

Ejercicios «prompt → código»

El libro de J. F. Puentes (Tecnologías Inteligentes, 2025) propone otra forma de trabajar: escribir un prompt a una IA (en Colab, el asistente Gemini), ejecutar el código que genera, entenderlo línea a línea y comprobar que hace lo que pedimos. La programación oficial de la materia sigue la misma idea. Estos prompts solo necesitan lo visto en la UD2.

# Prompt (adaptado) Libro Conceptos Nivel
P1 «Genera dos vectores de 8 enteros aleatorios, muéstralos y calcula su distancia euclídea y su similitud del coseno» cap. 6.4 NumPy, vectores 🟢
P2 «Convierte un texto en números: muestra el código Unicode de cada carácter y sus bytes en UTF-8» cap. 8.2 ord(), encode() 🟢
P3 «Haz una tabla de frecuencias de las palabras de un texto, de más a menos frecuente, con una barra de texto» cap. 8, 10 Counter, expresiones regulares 🟢
P4 «Carga un CSV desde una URL, muestra las primeras filas y un resumen estadístico» cap. 6.4 Pandas 🟢
P5 «Dada una imagen por URL, calcula y muestra su histograma como una sola línea» cap. 4.5 NumPy, Matplotlib 🟡

Para cada prompt, en tu diario: ¿qué pediste?, ¿qué librerías usó la IA?, ¿funcionó a la primera?, explica tres líneas del código con tus palabras y cambia algo (otro texto, otra imagen) para comprobar que lo entiendes.
