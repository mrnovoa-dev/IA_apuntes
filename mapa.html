Uno dentro de otro

Fórmula fácil: IA → inteligencia · ML → aprendizaje · DL → redes profundas · GenAI → generación. Están relacionados, pero no son sinónimos.

Tres formas de aprender

S
SupervisadoDatos con la respuesta correcta. El modelo aprende a predecirla. Clasificar spam, estimar el precio de una casa. UD3, UD4, UD5.
NS
No supervisadoDatos sin respuesta. El modelo busca grupos y patrones por sí mismo. Agrupar clientes parecidos. UD5.
R
Por refuerzoAprende probando: recibe premios o castigos. Juegos y robots. Se presenta en UD1.

Cómo aprende una red neuronal

Cada neurona hace z = w·x + b y aplica una activación. La red repite este ciclo miles de veces:

  1. ForwardLos datos atraviesan la red y sale una predicción
  2. PérdidaSe mide el error: MSE (números) o entropía cruzada (clases)
  3. BackpropagationRegla de la cadena: cuánto culpa tiene cada peso
  4. Actualizarw = w − tasa × gradiente
ReLUmax(0, z) · capas ocultas
Sigmoide0 a 1 · sí / no
Softmaxprobabilidades · varias clases

Contra el sobreajuste: más datos, dropout, early stopping, aumento de datos. CNN para imágenes (UD3), RNN/LSTM y Transformers para texto (UD4).

IA generativa: texto token a token

1 · Tokenizar"Me gusta Python" → ["Me", " gusta", " Py", "thon"]
2 · EmbeddingsCada token → un vector. Significados parecidos, vectores cercanos
3 · TransformerLa atención relaciona cada token con todos los demás
4 · Siguiente token" es" 41 % · " mucho" 22 % · "." 9 % → elige y repite

Temperatura baja = preciso; alta = creativo. Ventana de contexto = cuánto recuerda. RAG = buscar documentos antes de responder. Un buen prompt da contexto, rol, formato y ejemplos. Las alucinaciones existen: verifica siempre. UD3.

Hashing: por qué un dict vuela

Una función hash convierte la clave en una posición de la tabla: se accede directamente, sin recorrer nada. Por eso las claves deben ser inmutables.

O(1)
dict, set · 1 O(log n)
búsqueda binaria · 10 O(n)
buscar en list · 1 000 O(n log n)
sorted() · 10 000 O(n²)
2 bucles · 1 000 000
